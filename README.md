# Yashas HK — Interactive Portfolio

A responsive React + Vite portfolio featuring a live Bengaluru clock, light/dark theme toggle, resume download, project showcase, skills, education, and four browser mini-games.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy to Vercel with framework preset **Vite**, build command `npm run build`, and output directory `dist`.

## Included content

- Four projects from the supplied resume: SEO Rank Tracker, AI Fitness Tracker, MoodFlix, and React Chatbot.
- 12+ completed projects count, without inventing additional project cards.
- Resume download from `public/resume.pdf` (also available as `./resume.pdf` in this project).
- Bengaluru date and time, formatted for `Asia/Kolkata` and refreshed every second.
- Light/dark theme toggle.
- Four mini-games: Neon Pong, Neon Breaker, 2D Traffic Racer, and Reaction Sprint.
- Custom cursor on fine-pointer devices, disabled for touch and reduced-motion preferences.
